# Priyanka Studio — editable Arena handoff
Open index.html directly in a browser. No installation or paid service is required.
This is an independent editable recreation based on the existing site's content and style, NOT Wix's original editable project source or an exact pixel clone.
Files: index.html, style.css, app.js, gallery-data.js, photos.json and images/.
Includes gallery filters, keyboard-accessible image dialog, responsive layout, theme switch, phone and WhatsApp enquiry links. No login, payment or booking database is implemented. The phone is published on the existing site; verify WhatsApp availability with the client before launch.
Original observed style: olive text #44593a, Adobe Caslon serif headings and Avenir sans-serif body/section text. This recreation uses system Georgia/Arial fallbacks; it does not redistribute licensed fonts.
Scope: homepage, pre-wdiing, wedding-candid, work-03 and book-online. External Playbook albums and Instagram feeds are not downloaded. Videos are not included; some static video thumbnails are included.
