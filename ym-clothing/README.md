# YM Clothing storefront

Open `index.html` in Chrome, or deploy the folder on Netlify Drop / Vercel.

Each product card has a BUY NOW button that opens WhatsApp with the item details at +91 63663 06397. The cart, sizes, custom studio and mobile layout are included.

The currently used product photos load from external store image URLs, and can be replaced with YM Clothing's own approved photographs before public commercial use. Price and availability should be confirmed with YM Clothing. The Instagram profile picture URL may expire; save an authorized logo as `assets/ym-logo.jpg` to make it reliable.
